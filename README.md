# nemo-research

Мониторинг цен и скидок продавца **Nemo** на Kaspi + дашборд.

- **Сбор данных:** GitHub Actions раз в час парсит витрину Kaspi по merchantId (4 города),
  коммитит снимок в `data/`. Без сервера.
- **Дашборд:** статическая страница (`index.html`), деплой на Vercel. Читает CSV прямо из
  `data/` этого репозитория (raw GitHub), поэтому обновляется сам — Vercel пересобирать не нужно.

## Данные (`data/`)
| Файл | Что |
|------|-----|
| `latest.csv` | текущий снимок: строка на товар×город (`price`, `priceBeforeDiscount`, `discount`) |
| `changes.csv` | журнал изменений — строка только когда цена/скидка поменялись (главный файл для анализа) |
| `runs.csv` | сводка на каждый час (кол-во товаров, со скидкой, средняя скидка) |

## 1. Включить сбор (GitHub Actions)
1. Репозиторий уже содержит `.github/workflows/monitor.yml` (cron — каждый час, UTC).
2. Вкладка **Actions** → включить workflows → workflow **kaspi-price-monitor** → **Run workflow**
   (прогнать первый раз вручную; дальше сам по расписанию).
3. Бот коммитит `data/` каждый час.

> Публичный репозиторий → минуты Actions бесплатны и безлимитны.
> Cron в UTC и неточный (может опаздывать на 5–20 мин) — для мониторинга цен нормально.

Настройка города/продавца — в `monitor.yml`, блок `env:` (`MERCHANT`, `CITIES`).

## 2. Дашборд на Vercel
1. vercel.com → **Add New → Project** → импортировать этот репозиторий.
2. Framework Preset: **Other** (в `vercel.json` уже задано «без сборки, статика»).
3. Deploy. Готово — дашборд на `*.vercel.app`.

Дашборд оживёт, как только в `data/` появится первый снимок (после запуска Actions).

## Локальный запуск
```
pip install requests
python monitor.py                                   # один прогон 4 городов
python -m http.server 8899                          # открыть http://127.0.0.1:8899
```
